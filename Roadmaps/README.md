## 🧩 Path 1: GIS & Geospatial Analyst

*Master spatial reasoning, cartography, and desktop GIS software.*

| | 🟢 Stage 1 — Foundations | 🟡 Stage 2 — Software Mastery | 🔵 Stage 3 — Reporting & Analysis |
|:---:|:---|:---|:---|
| **Goal** | Understand spatial concepts & map design | Operate desktop GIS tools professionally | Perform and communicate spatial statistics |
| **Skills** | Coordinate systems, projections, map layers | ArcGIS / QGIS workflows, geoprocessing | Spatial statistics, layout design, reports |
| **Resources** | [Geospatial Analysis](../Courses/Geospatial-Analysis.md) · [Geovisualization](../Courses/Geovisualization.md) | [ArcGIS Mastery](../Courses/ArcGIS.md) · [QGIS Mastery](../Courses/QGIS.md) · [Cheat Sheets](../Cheat-Sheets/README.md) | [Spatial Statistics](../Courses/Spatial-Statistics.md) |
| **Milestone** | 🗺️ Create your first choropleth map | 🖥️ Complete a full geoprocessing workflow | 📊 Deliver a spatial insights report |

## 💻 Path 2: Geospatial Developer

*Build web maps, automate spatial workflows, and deploy geospatial applications.*

### 🎨 Frontend Track

| | 🟢 Stage 1 — Core Web | 🟡 Stage 2 — Map Libraries | 🔵 Stage 3 — Frameworks & Production |
|:---:|:---|:---|:---|
| **Goal** | Learn the building blocks of the web | Render interactive maps in the browser | Build production-ready geospatial apps |
| **Skills** | HTML, CSS, JavaScript | Leaflet.js, Mapbox GL JS, OpenLayers | React / Vue + pydeck / Kepler.gl |
| **Resources** | External Web Dev courses | [Geovisualization](../Courses/Geovisualization.md) | [Geospatial Developer](../Courses/Geospatial-Developer.md) |
| **Milestone** | 🌐 Build a static webpage | 🗺️ Embed an interactive slippy map | ⚡ Deploy a full spatial dashboard app |

### 🗄️ Backend Track

| | 🟢 Stage 1 — Scripting | 🟡 Stage 2 — Spatial APIs | 🔵 Stage 3 — Cloud & DevOps |
|:---:|:---|:---|:---|
| **Goal** | Automate GIS tasks with Python | Serve and query spatial data via APIs | Scale spatial services to the cloud |
| **Skills** | Python, ArcPy, PyQGIS, GDAL | FastAPI / Flask, PostGIS, REST design | Docker, serverless, cloud-native GIS |
| **Resources** | [Python for GIS](../Courses/Python.md) | [Geospatial Data Engineering](../Courses/Geospatial-Data-Engineering.md) | [Cloud Geospatial Tools](../Courses/Cloud-Geopstial-Tools.md) |
| **Milestone** | 🐍 Automate a batch geoprocessing task | 🔌 Serve a working spatial REST endpoint | ☁️ Deploy a scalable tile server |

## 🧪 Path 3: Geospatial Data Scientist

*Combine spatial data with machine learning and AI to generate predictive insights.*

| | 🟢 Stage 1 — Data Mastery | 🟡 Stage 2 — Machine Learning | 🔵 Stage 3 — Deep Learning |
|:---:|:---|:---|:---|
| **Goal** | Handle, clean, and explore spatial datasets | Apply ML models to geographic problems | Use neural networks with satellite imagery |
| **Skills** | GeoPandas, rasterio, spatial joins, EDA | Scikit-learn, spatial feature engineering | CNNs, Vision Transformers, SAR/optical fusion |
| **Resources** | [Geospatial Data Science](../Courses/Geospatial-Data-Science.md) | [Machine Learning for GIS](../Courses/Machine-Learning.md) · [GEE](../Courses/Google-earth-engine.md) | [Deep Learning for RS](../Courses/Deep-Learning.md) |
| **Milestone** | 🔍 Perform an EDA on a spatial dataset | 🤖 Train a land-use classification model | 🛰️ Segment features from a satellite image |

## ⚙️ Path 4: Geospatial Data Engineer

*Design and maintain robust spatial data infrastructure and cloud-scale pipelines.*

| | 🟢 Stage 1 — Spatial Databases | 🟡 Stage 2 — Pipelines & Orchestration | 🔵 Stage 3 — Cloud-Native Scale |
|:---:|:---|:---|:---|
| **Goal** | Store, index, and query spatial data efficiently | Automate ingestion, transformation & loading | Handle planetary-scale datasets in the cloud |
| **Skills** | PostGIS, Spatial SQL, indexing strategies | Airflow / Prefect, ETL design, data lakes | COG, Zarr, STAC, cloud object storage |
| **Resources** | [PostGIS & Spatial SQL](../Courses/Geospatial-Data-Engineering.md) | [ETL & Orchestration](../Courses/Geospatial-Data-Engineering.md) | [Cloud Geospatial Tools](../Courses/Cloud-Geopstial-Tools.md) |
| **Milestone** | 🗄️ Query a PostGIS database with spatial filters | 🔄 Build an automated geospatial ETL pipeline | ☁️ Serve a COG dataset via cloud object storage |

| **Goal** | Build deep domain expertise in earth sciences | Read, analyze, and apply scientific literature | Contribute original research and novel methods |
| **Skills** | Climate modeling, earth systems, GEE | Literature review, citations, methodologies | Advanced RS analysis, academic writing |
| **Resources** | [Climate Science](../Courses/Climate-science.md) · [GEE](../Courses/Google-earth-engine.md) | [Articles & Papers](../Articles-and-Papers/README.md) · [Books](../Books/README.md) | [Deep Learning for RS](../Courses/Deep-Learning.md) |
