# 🎓 Google earth engine Resources

## 🛰️ Google Earth Engine (GEE)
Google Earth Engine is a planetary-scale platform for Earth science data and analysis.

### 🛠️ Key Tools
- [**Earth Engine Code Editor**](https://code.earthengine.google.com/) - The web-based IDE for EE JavaScript API.
- [**geemap**](https://geemap.org/) - A Python package for interactive mapping with GEE and ipyleaflet.
- [**Google Earth Engine Python API**](https://developers.google.com/earth-engine/guides/python_install) - Access EE using Python.

### 📚 Learning Resources
- [**Awesome Google Earth Engine**](https://github.com/giswqs/Awesome-GEE) - A curated list of GEE resources.
- [**GEE Tutorials**](https://developers.google.com/earth-engine/tutorials) - Official Google tutorials.
- [**Google Earth Engine for Data Science**](https://www.google-earth-engine.com/) - Book by Wu Qiusheng.
