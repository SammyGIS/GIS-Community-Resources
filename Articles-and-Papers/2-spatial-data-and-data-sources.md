# 🌍 Spatial Data & Data Sources

Spatial data represents information about the physical location and shape of geographic features and the relationships between them.

## 💡 Core Concepts

*   **Vector Data**: Uses points, lines, and polygons to represent discrete features (e.g., city locations, roads, administrative boundaries).
*   **Raster Data**: Uses a grid of cells (pixels) to represent continuous data (e.g., satellite imagery, digital elevation models, temperature maps).
*   **Attributes**: Non-spatial information associated with geographic features (e.g., the name of a city, the population of a region).
*   **Metadata**: "Data about data" — provides context on the source, quality, and projection of the dataset.
